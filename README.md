# Portfolio — Clément Degardenzi

Site personnel de [Clément Degardenzi](https://clementdegardenzi.fr), Software Engineer Full-Stack.

Flutter · TypeScript/Node.js · Firebase/GCP · Java/Spring · React

## Stack

- React 18 + React Router + Vite
- Sass
- GSAP (animations)
- Projets chargés depuis `https://api.clementdegardenzi.fr/api/projects`

## Scripts

```bash
npm start        # http://localhost:3000
npm run build    # sortie dans /build (IONOS)
npm run preview
```
